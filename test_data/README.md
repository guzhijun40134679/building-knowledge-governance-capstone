# Test Data Policy

Real Welcome Letters and extracted business records are intentionally excluded from this English shareable copy.

Use only synthetic or explicitly sanitized fixtures in this directory. A useful fixture should preserve the document shape and edge case being tested without retaining real names, phone numbers, email addresses, unit numbers, account identifiers, signatures, or contractual details.

The public classroom fixtures are under [welcome_letters](welcome_letters/README.md). Files must use the `SYNTHETIC_` prefix so they cannot be confused with operational documents.
