# Synthetic Welcome Letter Fixtures

These fixtures are fictional and intended only for software testing. They use the reserved `example.com` domain, North American fictional-use `555-01xx` phone numbers, invented organizations and providers, and an intentionally fictitious address.

Import the January letter first and the June letter second to test:

- building matching and fixed-field extraction;
- source evidence and unchanged-field handling;
- conflict detection and human review;
- contact, COI, insurance, electricity, and internet-provider updates.

Expected conflicts include the property manager, contact details, key pickup, elevator reservation lead time, COI parties, insurance coverage, electricity setup, and internet-provider support.

Each fixture is provided as Markdown for easy inspection and as a matching PDF for document-intake testing. Never use these documents as real move-in instructions.
